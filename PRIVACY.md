# Privacy policy — claude-bugbash

**Last updated:** March 2026

This document describes how the **claude-bugbash** project (the open-source Claude Code plugin in this repository) relates to personal data. It is provided for transparency; it is not legal advice.

## What this project is

claude-bugbash is **documentation and configuration** (skills, commands, agent prompts, marketplace metadata) intended for use with **Claude Code**. This repository does **not** ship a separate server, SDK, or telemetry binary operated by the maintainers.

## Data the maintainers do not collect from this repo

The project itself does **not**:

- Run analytics or tracking code when you browse or clone this repository
- Operate a backend that receives usage data from the plugin
- Require an account with the maintainers to use the plugin

## Third-party services you may use alongside this project

When you use these services, **their** privacy policies and terms apply:

- **Anthropic / Claude Code** — Processing of prompts, tool use, and related data is governed by Anthropic’s policies for the product and plan you use.
- **Git host (e.g. GitHub)** — Cloning, stars, issues, pull requests, and web traffic may be processed as described in that platform’s privacy statement.
- **Your own applications** — If you use the plugin to test software you control, you remain responsible for that software’s data handling.

## Public collaboration

If you open issues, pull requests, or comments on a public repository, information you include there is **public** and may be indexed or copied like any other open-source project.

## Changes

This policy may be updated from time to time. The **Last updated** date at the top will change when it is revised meaningfully.
